# Interactive-Annual-Sales-Report-in-Excel.

## Project Overview
This project involves creating an interactive Excel dashboard to analyze and visualize a dataset containing various order-related data. The dataset includes columns such as `orderID`, `custID`, `orders`, `amounts`, `age`, `channels`, `month`, `ship_state`, `ship_city`, `order status`, and more. The dashboard utilizes different charts to provide insights into sales and customer behaviors across various metrics.

## Features and Charts

1. **Bar Chart of Orders by State**  
   Visualizes the total number of orders by state, helping to identify geographic trends.

2. **Pie Chart of Sales: Men vs Women**  
   Displays a distribution of sales based on gender, providing insights into demographic purchasing patterns.

3. **Column Chart of Orders vs Sales**  
   Compares the total number of orders to total sales amounts, offering a view of transaction volume vs revenue.

4. **Donut Chart of Order Status**  
   Visualizes the distribution of orders based on their current status (e.g., pending, shipped, delivered).

5. **Pie Chart of Order Channel (Amazon, Flipkart, etc.)**  
   Shows the proportion of orders from different sales channels, such as Amazon, Flipkart, etc.

6. **Column Chart of Order: Age vs Gender**  
   Examines the relationship between customer age and gender in the order data, helping to identify age and gender-based purchasing patterns.

## Interactive Features
- The dashboard allows users to filter and interact with the data by applying different slicers and pivot tables.
- Users can dynamically adjust the charts based on specific metrics such as month, channel and category.

## Instructions
1. Open the Excel file containing the dashboard.
2. Navigate through the dashboard sheet to explore the various charts.
3. Use slicers to filter data based on different criteria such as `month`, `state`, `age`, and `gender`.
4. Interact with each chart for detailed analysis and insights.

## Requirements
- Microsoft Excel (preferably 2016 or later)
- The dataset is already pre-loaded in the Excel file for analysis.

## Conclusion
This interactive dashboard provides a comprehensive view of customer and sales trends, allowing users to make data-driven decisions with ease.
